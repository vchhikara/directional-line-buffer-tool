# Pre-change audit findings: Directional Line Buffer 0.3.0

Prepared before implementation from the exact uploaded ZIP. File/line references refer to the original archive, not to the revised source. This record is the original audit baseline; final status is reported in `QGIS_PLUGIN_AUDIT_REPORT.md`.

| ID | Severity | Type | Category | Original location | Evidence and consequence | Remedy | Initial status |
|---|---|---|---|---|---|---|---|
| DLB-001 | High | Confirmed bug | Data integrity | `map_tool.py:177-202` | Finds any polygon layer named `Directional buffer` and calls `ensure_fields` on it. Can change a user's unrelated layer schema without authorization. | Reuse only plugin-owned memory layers, identify by custom property, and never add fields to unrelated layers. | Open |
| DLB-002 | High | Confirmed bug | CRS/data integrity | `map_tool.py:22-28,151-158`; `directional_line_buffer.py:51-58` | CRS is validated only on activation, but the project CRS is consulted again when saving. A mid-digitizing CRS change can reinterpret captured coordinates under a different CRS. | Capture source CRS, check for CRS changes before events and writing, cancel unsafe output. | Open |
| DLB-003 | High | Confirmed bug | Data integrity | `map_tool.py:163-175` | Broad `except Exception` returns `False` with no diagnostic. On edit commit failures, provider writes might be partially committed, but the automatic temporary-layer fallback can duplicate output. | Preserve and show errors; classify uncertain commit failures and suppress fallback in that case. | Open |
| DLB-004 | Medium | Confirmed bug | Geometry | `map_tool.py:45-64,99-105` | Left-click always adds the point, including a repeated coordinate; finishing accepts any two points even when coincident. Can generate null/invalid buffers and confusing behavior on double-click. | Remove adjacent repeated points; validate finite, nondegenerate line. | Open |
| DLB-005 | Medium | Confirmed risk | Lifecycle | `directional_line_buffer.py:39-49,65-74`; `map_tool.py:32-42` | Replacing or unloading map tools resets bands but does not explicitly dispose of Qt canvas items; repeated activation may leave hidden items. | Idempotent cleanup of bands, old map tool and QAction; prevent double menu registration. | Open |
| DLB-006 | Medium | Confirmed risk | Destination layer | `map_tool.py:128-149` | Uses `iface.activeLayer()` at finish rather than at start: an intervening layer selection could redirect writes. | Fix the intended target on activation, validate registration and writability at output time, explain destination in UI. | Open |
| DLB-007 | Medium | Confirmed bug | CRS | `directional_line_buffer.py:53` | `crs.mapUnits() != 0` uses magic numeric constant for meters; brittle and poorly documented. | Use `QgsUnitTypes.DistanceMeters`. | Open |
| DLB-008 | Medium | Confirmed risk | Editing/undo | `map_tool.py:165-169` | When target is already editable, direct `layer.addFeature` is not wrapped as a discrete undo command. | Use `beginEditCommand/endEditCommand/destroyEditCommand` for existing edit buffers. | Open |
| DLB-009 | Medium | Confirmed risk | Failure handling | `map_tool.py:93-110,112-125` | Buffer errors and coordinate transform errors may propagate; invalid geometry warning lacks diagnostic. | Catch expected errors at output boundary; produce actionable messages and preserve captured input on failure. | Open |
| DLB-010 | Medium | Confirmed risk | Temporary output | `map_tool.py:187-201` | Relies on `crs.authid()` string when creating memory layer and does not check successful field creation. May fail for valid custom CRS and attribute creation errors. | Set CRS on new memory layer explicitly; verify provider/fields. | Open |
| DLB-011 | Medium | Confirmed gap | Tests/QA | Entire archive | No tests or integration harness included. No evidence of line orientation, lifecycle, or packaging tests. | Add pure-unit, mocked API lifecycle, package validation and opt-in QGIS tests; state what was not executed. | Open |
| DLB-012 | Low | Confirmed gap | User documentation | `README.md` | No detailed installation steps, parameter examples, error diagnostics or local HTML help. | Expand accurate README/DEVELOPMENT/CHANGELOG; add usable offline help. | Open |
| DLB-013 | Low | Confirmed gap | Release | `metadata.txt:5,13`; archive | No source/release packaging scripts and no patch-version record of repairs. | Introduce auditable packaging script; bump patch to 0.3.1 for fixes and update changelog. | Open |
| DLB-014 | Low | Discretionary | UI/i18n | `buffer_dialog.py:1-29`; `map_tool.py` | Some UI strings not passed through `QCoreApplication.translate`; no actual translations. | Wrap new/existing UI text for future translation, but do not invent language files. | Open |
| DLB-015 | Low | Confirmation required | Release metadata | `metadata.txt:14-16` | Owner-provided URLs are plausible but their public accessibility and correspondence to release source have not been established. | Leave values unchanged, record external link verification requirement. | Open |

## Initial priority

Prevent unintended schema edits and CRS corruption before UI or release improvements; fix unsafe fallback behavior and lifecycle leaks next. Preserve single- and double-sided buffering, meter-only project constraint, direct digitizing, live preview, active polygon output with temporary fallback, and existing icon/license. Do not introduce a Processing provider or translation files because neither exists in the original plugin.
