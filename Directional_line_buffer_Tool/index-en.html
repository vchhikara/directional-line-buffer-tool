Directional Line Buffer

Draw a polyline directly on the QGIS map, preview a directional buffer and save the polygon. Requires a projected project CRS with meters as map units.

Quick start

  1. Set the project CRS to a projected meter-based CRS appropriate for your area.
  2. Choose the active polygon layer that should receive the result, if desired. Otherwise the plugin creates its own temporary polygon memory layer.
  3. Open Plugins > Directional Line Buffer > Directional Line Buffer. Confirm the destination shown in the dialog.
  4. Set distance (meters) and side. Left and right follow the order in which points are digitized.
  5. Left-click to place vertices. Right-click, double-click or press Enter to finish. Repeat for another buffer.
  6. Press Escape to discard the current line. With no unfinished line, Escape exits digitizing.

Output

When a writable, compatible polygon layer is selected at start, the plugin attempts to save to that layer. Otherwise it uses a temporary Directional buffer layer. If a safe output write is rejected, it attempts a temporary fallback; uncertain transaction commits are not retried automatically to avoid duplicate output. An editable layer retains the result as an undoable edit; a non-editing layer is committed automatically.

Attributes distance_m and side are populated if the destination has those fields. A new temporary layer contains both. Existing layer fields are never added by the plugin.

Restrictions and errors

The line needs two different points and a positive finite distance. The project and map canvas CRS must remain unchanged throughout digitizing. Sharp bends or crossing paths can produce invalid polygons and will be rejected without output. An incompatible destination layer will cause temporary output instead. Save temporary memory output to disk before closing the QGIS project.

Check View > Panels > Log Messages and the Directional Line Buffer category if an output attempt fails. Review any uncertain commit before attempting the same buffer again.
