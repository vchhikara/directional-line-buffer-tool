Directional Line Buffer

  1. Set a projected project CRS in meters. The canvas CRS must match.
  2. Optionally select a writable polygon output layer. Otherwise a temporary memory layer is used.
  3. Open the plugin, choose distance, side and round or flat road ends, then select OK. The window may be minimized while you draw.
  4. Left-click to add vertices. Backspace removes the last vertex. Right-click and choose Finish digitizing to save the buffer, or Clear digitizing to discard the line. Enter and double-click also finish the line.
  5. Draw more lines. Press Escape to clear a line; press it again on an empty canvas to exit the map tool. Use OK to start it again. Close the window to end the tool.

Left and right depend on drawing direction. Changing settings and pressing OK restarts the tool and clears any unfinished drawing. Select the desired output layer before opening the window.

Save temporary memory layers to a permanent file before closing the project. If a commit reports a possible partial write, inspect the destination before retrying.

Distances are planar in the project CRS. Choose a suitable projection. Existing layer constraints can prevent a write.
